Questions buyers ask

Do I need the API or a data license?

Take the API if your software needs live road reports or one mile marker at a time. Take a data license if you want the whole mile marker file, which you keep and which only needs a GPS position to look up a marker, or past alerts inside your own systems. You can buy both.

How are API calls counted?

An API call is one request your software sends to our server. Only requests that reach our server count toward your daily limit.

Can I try it before I pay?

Yes. A test key runs 14 days at 100 calls a day. The API page has a live test of the mile marker lookup. For a data license, ask for a sample file.

How do I get an API key?

Email sales@milecheckapp.com with what you are building. We send a key. The API page shows how to send it with each request.

Can I resell the data?

No. The dataset license lets you show the data in your product. It does not cover resale.

What if a state's feed has no crash data?

Ten states' live feeds do not carry crashes. The API says so for those states. It does not return a zero that looks like a quiet road.

Do you cover Canada?

Live alerts cover British Columbia, Alberta and Manitoba. The Milepost dataset also has kilometre markers for ten Canadian provinces and territories.

Where does the data come from?

Mile marker positions come from state DOT reference-marker datasets. Road alerts come from each state and provincial DOT feed. The data sources page lists each one.

Our mission

Become the trusted source for road information across North America, from today’s closures to next season’s roadwork.

What we do

We put every state’s Department of Transportation data in one place, on your phone, in your car and in your browser.

Our values

  • No ads in the app. Our website is free to use, so it has a clearly marked sponsor slot to help pay for it, without pop-ups.
  • Road data, not your data. We collect road data from state DOTs, not data about you. You don’t need an account, your mile marker is calculated on your phone, your trip history stays there, and we never sell your data.
  • Only what’s needed. Weather sends your approximate location to the National Weather Service, route planning sends your location and destination to Google, and wildfire alerts send a location rounded to about 7 miles only if you turn them on. Sentry receives anonymous crash reports, we count feature use without location or identity, and Apple or Google handles subscriptions.
  • Built for real roads. Nearly every feature exists because someone on a real road asked for it.
